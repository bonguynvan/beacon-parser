The rest of the toolkit

@bonv/beacon-parser Decode any AppMeasurement or Web SDK hit into typed JSON. Zero runtime dependencies. @bonv/beacon-playwright Capture hits in a Playwright test and assert on them with matchers like toHaveAdobeEvent. @bonv/tracking-plan Define a tracking plan as a typed object and validate captured hits against it. @bonv/beacon-cli npx beacon-qa runs a tracking plan against real flows in CI and exits non-zero on failure.
